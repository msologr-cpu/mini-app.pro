# Image Assets

Изображения исходного экспорта SurferSEO встроены прямо в HTML-страницы в формате data URI, чтобы исключить бинарные файлы и сохранить полную совместимость с ограничениями репозитория. Если требуется вынести их в отдельные файлы, сохраните base64-строки из `index.html` или `en/index.html` и восстановите изображения в нужном формате.
